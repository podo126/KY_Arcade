# KY Arcade — PIXEL ARCADE

쿵야 캐릭터가 등장하는 픽셀 아케이드 게임 모음입니다. 게임, 그래픽, 사운드, 라이브러리가 모두 **HTML 파일 하나**(`pixel_arcade_v1.1.8.html`)에 들어 있어서 빌드할 필요 없이 브라우저로 열면 바로 실행됩니다.

## 수록 게임

| No. | 게임 | 장르 | 인원 | 조작 |
|-----|------|------|------|------|
| 001 | 버블 쿵야 | 고정 화면 액션 | 1–2P | [A] 버블 · [B] 점프 · 점프 누른 채 버블 밟기 |
| 002 | 쿵야 런 | 횡스크롤 런앤건 | 1–2P | [A] 사격 · [B] 점프 · [C] 수류탄 · ▲ 위 조준 · ▼ 구르기 |
| 003 | 스타 스트라이커 | 세로 슈팅 | 1–2P | [A] 사격 · [B] 폭탄 |
| 004 | 레스토랑 디펜스 | 로그라이크 액션 | 1P | [A] 공격 · [B] 회피 · [C] 스킬 · [A] 누른 채 이동하면 방향 고정 |

캐릭터는 **양파쿵야**(양파를 던지는 원거리형)와 **주먹밥쿵야**(프라이팬을 휘두르는 근접형) 중에서 고릅니다. 난이도는 EASY부터 CRAZY까지 있습니다.

## 실행 방법

### 로컬
`pixel_arcade_v1.1.8.html`을 Chrome이나 Edge 같은 브라우저로 열면 됩니다. 처음 누르는 키나 클릭은 시작 화면을 닫는 데만 쓰입니다.

### Cloudflare 배포
`wrangler.jsonc`는 저장소 폴더 전체를 정적 에셋으로 올리도록 설정되어 있습니다. `.assetsignore`에 적힌 파일은 업로드에서 빠집니다.

```sh
npx wrangler deploy
```

배포한 뒤에는 `https://<worker 주소>/pixel_arcade_v1.1.8.html`로 접속합니다. 폴더에 `index.html`이 없어서 루트 주소(`/`)로 들어가면 게임이 열리지 않습니다. 루트에서 바로 열리게 하려면 파일 이름을 `index.html`로 바꾸세요.

| A / B / C / D | J K L ; | 숫자패드 1 2 3 4 | A / B / Y·LB / X·RB |
| 시작 | 1 / Space | 숫자 2 / 숫자패드 Enter | START |
| 코인 투입 | 5 / 6 | 5 / 6 | SELECT |
| 일시정지·메뉴 | Esc | Esc | — |

- 혼자 할 때는 방향키와 Z X C V로도 1P를 조작할 수 있습니다.
- 게임패드는 2개까지 인식합니다.
- 일부 게임은 마우스로도 조작할 수 있습니다.

## 설정과 저장 데이터

메인 화면의 설정 메뉴에서 다음 항목을 켜고 끌 수 있습니다.

- **프리 플레이**: 기본값은 켬입니다. 끄면 코인을 넣어야 게임을 시작하거나 이어할 수 있습니다.
- **사운드**
- **화면 필터**: CRT 느낌의 화면 효과입니다.
- **랭킹 초기화**

랭킹(게임별 TOP 10, 아이디·점수·날짜)과 화면 필터 설정은 브라우저의 `localStorage`에 저장됩니다. 그래서 기록은 기기와 브라우저마다 따로 남습니다.

| 키 | 내용 |
|----|------|
| `pixelArcadeRanking_v2` | 게임별 랭킹 |
| `pixelArcadeFilter` | 화면 필터 켬/끔 |

### 점수 공유 QR
랭킹에 오르면 QR 코드가 표시됩니다. 휴대폰으로 찍으면 `SHARE_URL`(현재 `https://share.koongya.workers.dev/`)의 공유 페이지가 열리고, 내 기록이 들어간 랭킹 이미지를 저장할 수 있습니다. 랭킹 데이터는 URL의 `#` 뒤에 base64url로 들어가므로 서버나 DB가 없어도 동작합니다. 공유 페이지(`share.html`)는 이 저장소에 없습니다.

### Supabase (작업 중)
파일 끝부분에서 Supabase 클라이언트(`sb`)를 만들지만, 아직 이 클라이언트를 사용하는 코드는 없습니다. 지금은 랭킹이 전부 `localStorage`에만 저장됩니다. 코드에 들어 있는 키는 브라우저 공개용 publishable 키입니다. 온라인 랭킹 기능을 붙일 때는 테이블에 RLS 정책을 꼭 설정하세요.

## 파일 구조

```
pixel_arcade_v1.1.8.html   게임 본체 (단일 파일)
wrangler.jsonc             Cloudflare Workers 정적 에셋 배포 설정
.assetsignore              배포에서 제외할 파일 목록
README.md
```

HTML 안의 `<script data-src="...">` 블록은 원래 따로 있던 모듈 파일을 하나로 합친 것입니다. 어떤 기능을 고칠지 찾을 때 참고하세요.

| 모듈 | 역할 |
|------|------|
| `assets/sound.js` | 효과음·BGM |
| `assets/qrcode.min.js` | QR 코드 생성 |
| `assets/characters.js` | 캐릭터 스프라이트 |
| `core/util.js`, `difficulty.js` | 공용 유틸리티, 난이도 |
| `games/bubble.js`, `kyrun.js`, `star.js`, `restaurant.js` | 게임 4종 |
| `games.js` | 게임 목록 (번호·이름·장르·조작 설명) |
| `cutscene.js` | 인트로 컷신, 타이틀 |
| `shell.js` | 런처, 입력, 코인, 랭킹, 설정 |

새 게임을 추가하려면 게임 클래스를 작성하고 `GAMES` 배열에 항목을 하나 추가하면 됩니다.
